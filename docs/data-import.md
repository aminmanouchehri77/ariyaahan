# راهنمای ورود کاتالوگ و قیمت

هر دو فرمان ابتدا فقط اعتبارسنجی می‌کنند. برای نوشتن در MySQL باید گزینهٔ --commit را صریحاً بدهید. ورود دسته‌ای در یک تراکنش انجام می‌شود؛ اگر یک ردیف نامعتبر باشد، هیچ ردیفی ثبت نمی‌شود.

## کاتالوگ

قالب: docs/catalog-import-template.csv

ستون‌های لازم:

- category_slug: شناسهٔ دسته‌ای که قبلاً در پنل مدیریت ساخته شده است.
- product_slug و product_name: شناسهٔ یکتا و نام محصول.
- variant_sku و variant_name: کد یکتا و نام گونهٔ قابل فروش.
- unit: یکی از kg, ton, piece, bundle, sheet, meter.

توضیح، سایز، گرید، استاندارد، ابعاد و وزن هر واحد اختیاری‌اند. اگر کارخانه مشخص است، manufacturer_slug و manufacturer_name را با هم وارد کنید. این فرمان محصولات و SKUهای موجود را بازنویسی نمی‌کند.

    python manage.py import_catalog .\catalog.csv
    python manage.py import_catalog .\catalog.csv --commit

## قیمت‌ها

قالب: docs/price-import-template.csv

variant_sku، amount، currency و price_basis لازم‌اند. ارز می‌تواند IRR، IRT یا USD باشد. واحد مبنا می‌تواند kg، ton، piece، bundle، sheet یا meter باشد. زمان‌ها در صورت ورود باید ISO 8601 همراه منطقهٔ زمانی باشند؛ نمونه: 2026-11-04T12:30:00+03:30. زمان اعتبار خالی یعنی قیمت برای محاسبهٔ پیش‌فاکتور معتبر نیست.

    python manage.py import_prices .\prices.csv
    python manage.py import_prices .\prices.csv --commit

قیمت‌ها با وضعیت «در انتظار تأیید» وارد می‌شوند. مدیر قیمت را در پنل مدیریت بررسی و تأیید می‌کند؛ ثبت قیمت بعد از ساخت تغییرپذیر نیست و اصلاح آن باید با ثبت تازه انجام شود. قیمت‌های تأییدنشده در سایت، دادهٔ ساخت‌یافتهٔ محصول و خروجی جست‌وجو دیده نمی‌شوند.

فایل CSV باید UTF-8 باشد. نسخهٔ نهایی کاتالوگ و مبلغ‌ها را تیم آریا از منبع مورداعتماد شرکت تهیه می‌کند؛ نمونهٔ قیمت ساختگی در پروژه وارد نشده است.
