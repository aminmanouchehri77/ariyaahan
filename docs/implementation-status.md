# وضعیت پیاده‌سازی مشخصات سایت آریا

**آخرین بازبینی:** ۵ نوامبر ۲۰۲۶

## قابلیت‌های پیاده‌سازی‌شده

- پروژهٔ Django با رندر سمت سرور و MySQL محلی، اتصال `utf8mb4` و تنظیم محیط از `.env`؛ فایل واقعی `.env` و فایل‌های محلی credential از Git خارج هستند.
- ورود مشتری با OTP، محدودیت ارسال و تلاش، خروج امن، پروفایل، نشانی‌ها و سفارش‌های مشتری. backend کاوه‌نگار آماده است و در توسعهٔ محلی backend کنسول استفاده می‌شود.
- دسته، محصول، گونه و کارخانه؛ واردسازی کاتالوگ و قیمت از CSV؛ بررسی مدیر برای قیمت و موجودی؛ فیلتر، مرتب‌سازی، جست‌وجوی پیشنهادی، مقایسهٔ چهارتایی و تاریخچهٔ قیمت.
- هشدار قیمت و صندوق اعلان داخل حساب؛ خبر تغییر قیمت از دو ثبت تأییدشده و هم‌ارز ساخته می‌شود. خبرهای بدون دادهٔ قابل مقایسه ساخته نمی‌شوند.
- سبد، پیش‌فاکتور با snapshot قیمت و مقصد، تأیید مدیر و ساخت سفارش فقط وقتی snapshot هنوز معتبر است؛ گردش وضعیت سفارش تاریخچه دارد.
- تالار عرضه و تقاضای نیازمند بازبینی، فرم تماس/شکایت/پیشنهاد/استخدام/صادرات، صفحات شرکت، مقاله، پرسش متداول، ویدیو، پادکست و پرسش محصول.
- محاسبه‌گر وزن، محاسبهٔ حمل بر پایهٔ نرخ فعال ثبت‌شده، sitemap، robots، canonical، دادهٔ ساختاریافته، تغییرمسیر داخلی اعتبارسنجی‌شده و صفحات خطای ۴۰۴/۵۰۰.
- PWA با manifest، نصب، Service Worker، صفحهٔ آفلاین بدون قیمت کش‌شده و event handler اعلان مرورگر. فایل Digital Asset Links از تنظیمات نهایی تولید می‌شود.
- گروه‌های دسترسی استاندارد پنل با فرمان `setup_staff_roles` ایجاد شده‌اند؛ کاربرها باید دستی و بر اساس مسئولیت به گروه مناسب افزوده شوند.

## موارد وابسته به تصمیم یا اطلاعات شرکت

- **پرداخت:** درگاه انتخاب نشده و کلید پذیرنده وجود ندارد؛ فعلاً پیش‌فاکتور و چرخهٔ سفارش پیاده شده است و پرداخت واقعی اجرا نمی‌شود.
- **کاوه‌نگار:** API key و نام دقیق الگوی Verify Lookup تأییدشده باید توسط شرکت وارد شود؛ تا آن زمان OTP فقط در کنسول محلی ظاهر می‌شود.
- **دادهٔ عملیاتی:** قیمت تأییدشده، موجودی، نرخ‌های حمل، متن رسمی شرکت/قوانین، آدرس و شماره‌های تماس باید از منبع معتبر شرکت وارد شوند.
- **TWA:** دامنهٔ عمومی HTTPS، شناسهٔ بستهٔ Android و fingerprint گواهی انتشار لازم‌اند. فایل `assetlinks.json` تا واردشدن مقادیر معتبر عمداً ۴۰۴ می‌دهد. ساخت و امضای APK/AAB در این پروژه انجام نشده است.
- **ارسال Web Push:** ثبت اشتراک مرورگر در backend آماده شده، اما sender شبکه‌ای فعال نشده است. بازبینی خودکار، نوشتن کدی را که اعلان مشتری را به endpoint سرویس push بیرونی ارسال می‌کند رد کرد. تا دریافت تأیید روشن دربارهٔ مقصدهای سرویس و payload مجاز، `PUSH_DELIVERY_ENABLED=0` می‌ماند.

## محدودیت نسخهٔ فعلی

- صفحهٔ روند قیمت ۳۰ ثبت اخیر با ارز، واحد و محل یکسان را نمایش می‌دهد؛ انتخاب بازهٔ زمانی دلخواه هنوز پیاده نشده است.
- تالارها، صفحات شرکت و کاتالوگ برای نمایش محتوای واقعی به داده و متن تأییدشده نیاز دارند.
- رابط‌ها و نصب TWA باید پس از استقرار روی دامنهٔ HTTPS نهایی با Chrome و Play Console بازبینی شوند؛ در این مرحله آزمون مرورگری/آزمون نرم‌افزار اجرا نشده است.
